What do you want to learn in this course?

To be honest, I did not expect this course to use code as an input to create visual outputs. I have always struggled with coding, so I was a little nervous at first. However, I think this could be a good challenge for me and a chance to become more comfortable with coding while using it in a creative way.

Tell us about an early experience with computers or the internet

I learned to use computers when my father was still using floppy disks. Back then, even sending an email could take a long time. Now, computers are much faster and technology is something we can carry right inside our pockets. It is interesting to see how much technology has changed in such a short time.

What will the web look like in 10 years from now?

I would say that if we keep moving in this direction, everything will become much simpler and easier to use. Maybe in the future, we will not even have to code anything ourselves because technology will be able to do most of the work for us. I think this could make coding more accessible to everyone.
